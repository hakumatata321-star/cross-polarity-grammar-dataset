# Cross-Polarity Spectrum Batches with Same-Compound Group Labels

900 compound families, 2,700 batches, 103,849 acquisitions and 3,033,843 peaks.

**The label is a partition, not a pairing.** For each batch, the answer is which of its acquisitions came
from the same compound. It is not a correspondence between one positive-mode spectrum and one
negative-mode spectrum, and it is not a property of any single spectrum.

A batch is a pile of acquisitions, not a list of compounds. Each compound is acquired zero to three times
in positive ionization mode and zero to three times in negative mode, so the correspondence between the
two polarities is many-to-many and the answer is a partition of the batch rather than a pairing. Three
degradations are applied and never marked: co-isolation of a neighbouring compound, detector saturation,
and low injection.

- **Origin:** fully synthetic, generated by the creator from a withheld fragmentation grammar. Every draw
  and identifier derives from HMAC-SHA256 keyed to a secret that is not published. This is a stylised
  grammar, not a model of real fragmentation chemistry, and it contains no record of any spectral library,
  no real compound and no third-party material.
- **`gen.py` is the generator that produced this release.** It needs the withheld secret to produce
  anything, so publishing it regenerates nothing and reveals no answer; it is here so the construction
  described in the dataset description can be checked against code rather than taken on faith.
- **Files:** `acquisitions.csv` (`case_id`, `block_id`, `slot`, `polarity`), `peaks.csv` (`case_id`, `slot`, `mz`, `log_intensity`) and `grouping.csv` (`case_id`, `slot`, `compound_group`, the answer key), plus `DATASET_DESCRIPTION.md` and `LICENSE`. There is no `spectra.csv`: a spectrum is the set of `peaks.csv` rows sharing a `case_id` and `slot`.
